## Аудит 2026-06-30 (после Task #5: напоминания/оценка/подзадачи)

### Исправлено

#### tasks_handlers.py — 3 бага в новом коде
- **HH:MM parser**: `now_utc.replace(hour=h, minute=mi)` без try/except → `ValueError` при `hour=25` или `minute=60` → FSM зависала, пользователь не видел ошибку. Обёрнуто в `try/except ValueError: pass`.
- **«Завтра утром»**: `minutes=1440` = ровно +24ч от сейчас, не реальное утро. Заменено на `minutes=0` → следующий день в 09:00 UTC (`(now + timedelta(days=1)).replace(hour=9, minute=0, ...)`).
- **admin.py backup restore**: `except Exception as exc: message = str(exc)` → `message[:300]` шло в URL-параметр `?detail=`, т.е. трассировка SQLite/OS ошибки была видна в браузере. Заменено на `logging.error(exc)` + generic message.

## Что проверять при новых изменениях
- Новый web POST, создающий ресурс → `check_*_limit()` + `if not verify_csrf_token(...)`
- Новый API endpoint → `_api_csrf_ok()` или `X-Requested-With` в fetch
- Новый метод агрегации → SQL GROUP BY/JOIN, не Python-цикл
- Новый парсинг пользовательского ввода → `try/except ValueError` вокруг `datetime.replace()`
- `str(exc)` в HTTP-ответах от `except Exception` → ЗАПРЕЩЕНО; только logging + generic
- Файловые загрузки → `_safe_filename()` + uuid prefix
- Новый inline on* в HTML → нарушает CSP nonce-policy, использовать ds-delegate.js
