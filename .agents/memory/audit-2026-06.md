- `get_seller_total_earnings` N+1 в salary.py (и Excel-экспорте): внутри — `get_joint_bonus_adjustment` + `get_notification_settings` + `plan_coeff` — цепочка вложенных вызовов; bulk требует отдельного рефакторинга мотивационной системы

## Что проверять при будущих изменениях
- Новый web POST, создающий ресурс → обязательно `check_*_limit()` + `if not verify_csrf_token(...)`
- Новый API endpoint → `_api_csrf_ok()` или `X-Requested-With` header в fetch
- Новый метод агрегации данных → SQL GROUP BY/JOIN, не Python-цикл по всем строкам
- Новый индекс → добавлять в `create_tables()` через `CREATE INDEX IF NOT EXISTS`
- `str(exc)` в HTTP-ответах → ЗАПРЕЩЕНО; только `logging.error/exception(...)` + generic 500
- Файловые загрузки → `_safe_filename()` + uuid prefix, путь строго server-controlled
