# Выделенная AI-тема в общем чате (веб)

Раньше в любой теме сообщение с префиксом `@ии`/`/ai`/`@ai` запускало ответ AI прямо
в той теме. Теперь AI живёт в одной выделенной теме «🤖 AI-ассистент»; префикс-хук
полностью удалён — в обычных темах AI не отвечает.

## Маркировка
- Колонка `chat_topics.is_ai` (миграция через PRAGMA + ALTER; partial UNIQUE index
  `WHERE is_ai=1` → не более одной AI-темы; гонку первого создания ловит
  `ensure_ai_topic()` через except→re-select).
- `get_chat_topics()` отдаёт `is_ai` 7-й колонкой; `_fmt_topic` читает её мягко
  (`row[6] if len(row)>6`).
- `get_ai_topic_id()` / `ensure_ai_topic()` (реактивирует, если кто-то заархивировал).
- rename/archive AI-темы заблокированы на уровне БД (как тема «Общий» id=1).

## Гейтинг (важно — двойной)
- Тема создаётся лениво в `chat_page` ТОЛЬКО при оплаченном расширении
  `ai_chat_assistant` (`_ai_ext_ok`).
- В `/chat/send` триггер срабатывает по факту `topic_id == get_ai_topic_id()`
  (расширение там НЕ проверяется) — но воркер `_ai_chat_reply` повторно гейтит на
  `has_extension` + дневной лимит. **Why:** если расширение протухло, а тема осталась,
  отправка просто не даёт ответа (no-op), а не утечку платной фичи.

**How to apply:** при изменениях потока чата помнить, что AI-тема определяется флагом
`is_ai`, а не именем/id; единственное условие срабатывания AI — текущая тема = AI-тема.
