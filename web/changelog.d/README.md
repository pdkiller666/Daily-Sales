# Фрагменты новостей («Что нового»)

Это «входящие» для раздела **Что нового** в веб-кабинете.

## Зачем

Раздел новостей живёт в `web/changelog.py` (`CURRENT_VERSION` + `ENTRIES`).
Если редактировать этот файл напрямую из разных веток (а фичи делают параллельные
агенты-задачи), получаются конфликты слияния, и новости протухают.

Вместо этого каждый, кто выкатывает пользовательскую фичу, кладёт сюда **отдельный
маленький файл-фрагмент**. Имена уникальные → конфликтов слияния нет. При деплое
`scripts/build_changelog.py` собирает все фрагменты в новую запись версии, поднимает
`CURRENT_VERSION`, (опционально) полирует формулировки через LLM и удаляет фрагменты.

## Как добавить новость

Создайте файл `web/changelog.d/<уникальное-имя>.md` (например по номеру задачи:
`task-42.md` или короткий slug `inventory-search.md`). Содержимое — **одна строка
на одну новость** (можно несколько строк = несколько пунктов):

```
✏️ Редактирование продажи прямо в окне: удаление, изменение даты, история изменений
```

Правила:
- Пишите с точки зрения **владельца магазина**, не разработчика.
- Эмодзи в начале — желательно, но не обязательно (AI-полировка добавит стиль).
- Строки, начинающиеся с `#`, и пустые строки игнорируются.
- НЕ редактируйте `web/changelog.py` руками — он собирается автоматически.

## Сборка вручную (необязательно)

```bash
python3 scripts/build_changelog.py --dry-run   # показать результат без записи
python3 scripts/build_changelog.py             # собрать (minor-бамп версии)
python3 scripts/build_changelog.py --major     # major-бамп
python3 scripts/build_changelog.py --patch     # patch-бамп
python3 scripts/build_changelog.py --no-ai     # без LLM-полировки
```

При деплое (`bash deploy.sh "..."`) сборка запускается автоматически.
