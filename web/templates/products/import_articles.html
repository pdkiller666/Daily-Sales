⚠️ Как работает

  • • Совпадение по названию товара (без учёта регистра)
  • • Артикул перезаписывается у существующих товаров
  • • Если артикул уже занят другим товаром — строка пропускается с предупреждением
  • • Если товар не найден — строка пропускается с предупреждением
  • • Максимум {{ max_items }} строк за загрузку
  • • Только формат .xlsx (не .xls, не .csv)

💡 Подсказка

Товары без артикулов можно сначала экспортировать из Excel-выгрузки — там есть столбец «Артикул». Заполните его и загрузите обратно.
