Как работает оргструктура

  • Подразделения — отделы, магазины и регионы. В полном режиме можно строить иерархию (регион → магазины).
  • Роли — собственные должности с набором прав и доступом к модулям. Назначаются сотрудникам на странице «Команда».
  • Доступ к модулям — индивидуально включайте/отключайте разделы для каждого сотрудника.
Базовый режим
  • ✓ До {{ minimal_limit }} подразделений (плоский список)
  • ✓ Стандартные роли (владелец / админ / сотрудник)
  • — Без иерархии и регионов
  • — Без кастомных ролей
⭐ Полный режим
  • ✓ Неограниченные подразделения + иерархия
  • ✓ Регионы и вложенность
  • ✓ Кастомные роли с правами
  • ✓ Доступ к модулям по сотруднику
