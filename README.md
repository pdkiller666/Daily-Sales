# Daily Sales — Telegram Bot для управления продажами

Профессиональный мультитенантный Telegram-бот для управления магазинами, продажами, персоналом и подписками. Поддерживает несколько организаций с полной изоляцией данных.

---

## 🚀 Возможности

### 🏢 Мультиарендность (Multi-tenancy)
- Несколько организаций — каждая со своей изолированной базой данных
- Система ролей: **Директор (owner)** → **Администратор (admin)** → **Сотрудник (user)**
- Зоны доступа: по магазину / городу / торговой сети (мульти-выбор)
- Кастомные названия должностей
- Инвайт-коды для вступления в организацию
- Суперадмин с возможностью переключения контекста между организациями

### 💰 Продажи и инвентарь
- Быстрая регистрация продаж (одиночная и мультикорзина)
- Быстрый поиск товара: «🔍 Найти товар» с поиском по ненулевому остатку
- Кнопки количества [1, 2, 3, 5, 10, 20, 50] — без ввода текста
- Управление каталогом товаров с категориями и ценами
- Импорт товаров из Excel (📊 Импорт из Excel)
- Избранные товары (⭐ Избранное) и недавние (🔄 Недавние)
- Быстрое подтверждение (⚡ Продать сейчас) при первом товаре в корзине
- Складской учёт с историей изменений
- Редактирование и удаление продаж с корректировкой остатков
- Кросс-продажи: сотрудник торговой сети может оформить продажу/списание из другого магазина сети

### 📊 Отчёты и аналитика
- Дашборд для администратора: смены, продажи сегодня, мотивация команды, все планы
- Дашборд для сотрудника: зарплата, планы, конкурсы
- Отчёты по периодам: общий / по магазину / по городу (с ручным фильтром)
- «Текущий месяц» — быстрый отчёт сотрудника с 1-го по сегодня
- Рейтинги продавцов, магазинов, городов (7 дней / этот месяц / прошлый)
- Позиция пользователя вне топ-10
- Экспорт данных в Excel
- Автоматические ежедневные отчёты
- Все времена отображаются в часовом поясе пользователя

### 🎯 Планы продаж
- Планы для продавца или магазина
- Периоды: неделя / месяц
- Метрики: оборот (₽) / количество (шт)
- Фильтр по категории или конкретному товару (мульти-выбор)
- Редактирование всех параметров плана
- Уведомления о достижении 50% / 75% / 100% — однократно за период
- Прогресс-бары в дашборде и «Моих планах»

### 📅 Зарплата и графики работы
- Ставки сотрудников (daily_rate)
- Календарь смен с отметкой рабочих дней
- Время начала и конца смены для каждого дня
- **Шаблоны смен** (⏰ Расписание смен): настройка типового расписания по дням недели (Пн–Вс)
- При добавлении смены автоматически применяется шаблон дня недели
- Сотрудник видит своё расписание и времена смен
- Зарплатный итог за месяц

### 🏆 Конкурсы
- Создание конкурсов с датами, призами и метриками
- Автоматическое подведение итогов (APScheduler)
- Архив конкурсов с очисткой по подтверждению

### 🔍 Ручные фильтры
- Кнопка «🔍 Фильтр» в Отчётах, Рейтингах, Сотрудниках, Прогрессе планов
- Мульти-выбор по магазину / городу / торговой сети
- Scope роли — потолок, ручной фильтр — пол

### 💎 Монетизация (Freemium)
- Тарифные планы: Бесплатный / Базовый / Стандарт / Премиум / Бизнес
- Промокоды со скидками и лимитами использования
- Пробный период (настраиваемые дни и план)
- Приём заявок на оплату с фото-чека
- Подтверждение платежей администратором

### 🔔 Уведомления
- Уведомления о низких остатках
- Уведомления о новых продажах за 24 часа
- Массовые и запланированные рассылки от администратора
- Запланированные уведомления: ввод в локальном времени → хранение UTC → отправка точно по времени
- Кнопка «✅ Прочитано» на всех push-уведомлениях — удаляет сообщение
- Напоминания об окончании подписки (за 14 / 7 / 3 / 1 день)

### 🎓 Onboarding и подсказки
- Welcome-попап при первом входе (роль-зависимый текст)
- Inline-подсказки при первом визите каждого раздела (однократно)
- Кнопка «✅ Понятно!» закрывает подсказку

## 🛠 Быстрый старт

### Требования
- Python 3.11+
- Replit (рекомендуется) или любой Linux-хост

### Установка

```bash
git clone https://github.com/pdkiller666/Daily-Sales.git
cd Daily-Sales
pip install -r requirements.txt
```

### Переменные окружения

| Переменная | Описание | Обязательно |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | ✅ |
| `ADMIN_CHAT_ID` | Telegram ID супер-администратора | ✅ |
| `GITHUB_TOKEN` | Токен для деплоя на GitHub | для деплоя |

На Replit все переменные хранятся в **Secrets** (не в `.env`).

### Запуск

```bash
python main.py
```

## 🏗 Архитектура

- **Multi-tenancy**: каждая организация получает изолированную SQLite БД (`data/tenants/org_*.db`)
- **Anchor message pattern**: все FSM-флоу редактируют одно сообщение через `fsm_edit()`
- **APScheduler**: 7 фоновых задач (продажи, отчёты, конкурсы, бэкап, уведомления)
- **Timezone-aware**: все времена хранятся как UTC, отображаются в TZ пользователя
- **Filters**: scope роли — потолок, ручной фильтр — пол; global FSM key `admin_filter`
- **Hosting**: Amvera (production), Replit (development); persistent mount `/app/data`
