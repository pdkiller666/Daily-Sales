# Daily Sales — Telegram Bot для управления продажами

Профессиональный мультитенантный Telegram-бот для управления магазинами, продажами, персоналом и подписками. Поддерживает несколько организаций с полной изоляцией данных.

---

## 🚀 Возможности

### 🏢 Мультиарендность (Multi-tenancy)
- Несколько организаций — каждая со своей изолированной базой данных
- Система ролей: **Директор (owner)** → **Администратор (admin)** → **Сотрудник (user)**
- Зоны доступа: по магазину / городу / торговой сети (мульти-выбор)
- Кастомные названия должностей
- Инвайт-коды для вступления в организацию
- Суперадмин с возможностью переключения контекста между организациями

### 💰 Продажи и инвентарь
- Быстрая регистрация продаж (одиночная и мультикорзина)
- Управление каталогом товаров с категориями и ценами
- Bulk-импорт товаров из текста
- Складской учёт с историей изменений
- Редактирование и удаление продаж с корректировкой остатков

### 📊 Отчёты и аналитика
- Дашборд для администратора: смены, продажи сегодня, мотивация команды
- Дашборд для сотрудника: зарплата, планы, конкурсы
- Отчёты по периодам: общий / по магазину / по городу
- Рейтинги продавцов и магазинов (7 дней / месяц / прошлый месяц)
- Экспорт данных в Excel
- Автоматические ежедневные отчёты

### 🎯 Планы продаж
- Планы для продавца или магазина
- Периоды: неделя / месяц
- Метрики: оборот / количество единиц
- Фильтр по категории или конкретному товару
- Редактирование всех параметров плана

### 🏆 Конкурсы
- Создание конкурсов с датами и призами
- Автоматическое подведение итогов (APScheduler)
- Архив конкурсов с очисткой

### 💎 Монетизация (Freemium)
- Тарифные планы: Бесплатный / Базовый / Стандарт / Премиум / VIP
- Промокоды со скидками и лимитами использования
- Пробный период (trial)
- Приём заявок на оплату с фото-чека
- Подтверждение платежей администратором

### 🔔 Уведомления
- Персонализированные уведомления о низких остатках
- Уведомления о новых продажах за 24 часа
- Массовые рассылки от администратора
- Напоминания об окончании подписки

## 🛠 Быстрый старт

### Требования
- Python 3.11+
- Replit (рекомендуется) или любой Linux-хост

### Установка

```bash
git clone https://github.com/pdkiller666/Daily-Sales.git
cd Daily-Sales
pip install -r requirements.txt
```

### Переменные окружения

| Переменная | Описание | Обязательно |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | ✅ |
| `ADMIN_CHAT_ID` | Telegram ID супер-администратора | ✅ |
| `GITHUB_TOKEN` | Токен для деплоя на GitHub | для деплоя |

На Replit все переменные хранятся в **Secrets** (не в `.env`).

### Запуск

```bash
python main.py
```

## 🚢 Деплой (GitHub + Amvera)

```bash
# Деплой на GitHub и Amvera (по умолчанию)
```

## ⚙️ Архитектурные решения

- **Мультиарендность**: каждая организация получает собственный SQLite-файл; `get_db()` маршрутизирует автоматически
- **Anchor message**: все FSM-флоу редактируют одно сообщение через `fsm_edit()`; `clear_state_keep_org()` вызывается строго **после** редактирования
- **HTML-безопасность**: все пользовательские строки в HTML-сообщениях оборачиваются в `he()` из `utils.py`
- **Callback 64 байта**: длинные строки (названия магазинов и т.п.) хранятся через `safe_cb()` / `resolve_cb_name()`
- **Зоны доступа**: `scope_value` хранится как JSON-массив, `get_user_org_scope()` → `(scope_type, list[str])`
- **Миграции на лету**: `create_tables()` вызывается внутри `get_db()` — новые таблицы создаются автоматически при первом обращении

## 🔄 Автоматические задачи (APScheduler)

| Время | Задача |
|---|---|
| Каждые 30 мин | Уведомления о продажах за 24 часа |
| Каждый час | Напоминания о платежах |
| 20:00 (по таймзоне) | Ежедневные отчёты |
| По расписанию пользователя | Уведомления о низких остатках |
| Каждые 15 мин | Запланированные уведомления |
| Каждые 10 мин | Автозавершение конкурсов |
| 03:00 | Резервное копирование |
