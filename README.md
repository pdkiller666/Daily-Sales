# Telegram Shop Management Bot

Профессиональный Telegram бот для управления товарами, продажами и подписками с полноценной монетизацией через freemium модель.

## 🚀 Основные возможности

### 📦 Управление товарами и остатками
- Добавление, редактирование и удаление товаров
- Управление категориями и ценами
- Автоматический контроль остатков
- Персонализированные уведомления о низких остатках

### 💰 Система продаж
- Быстрая регистрация продаж
- История и аналитика продаж
- Редактирование записей
- Рейтинги продавцов и магазинов

### 📊 Отчетность и аналитика
- Ежедневные автоматические отчеты
- Отчеты по периодам и магазинам
- Экспорт данных в Excel
- Расширенная аналитика для премиум пользователей

### 💎 Система подписок (Freemium)
- **Бесплатный** - базовый функционал
- **Базовый** (500₽/мес) - расширенные возможности
- **Стандарт** (1200₽/3мес) - множественные магазины
- **Премиум** (4000₽/год) - полная аналитика
- **VIP** (9999₽/год) - безлимитный доступ

### 🎁 Система промокодов
- Создание и управление промокодами
- Автоматическое применение скидок
- Отслеживание использования
- Интеграция с процессом покупки

### 🔧 Административные функции
- Управление пользователями и подписками
- Обработка платежей
- Резервное копирование данных
- Система уведомлений

## 🛠 Быстрый старт

### Локальная установка

1. **Клонирование проекта:**
```bash
git clone <repository-url>
cd telegram-shop-bot
```

2. **Установка зависимостей:**
```bash
pip install aiogram python-dotenv openpyxl apscheduler
```

3. **Настройка окружения:**
Создайте файл `.env`:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_CHAT_IDS=123456789,987654321
```

4. **Запуск:**
```bash
python main.py
```

### Docker развертывание

1. **Быстрый запуск:**
```bash
docker-compose up -d
```

2. **Сборка и запуск:**
```bash
docker build -t shop-bot .
docker run -d --name shop-bot --env-file .env -v ./data:/app/data shop-bot
```

## ⚙️ Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательно |
|------------|----------|-------------|
| `BOT_TOKEN` | Токен Telegram бота | ✅ |
| `ADMIN_CHAT_IDS` | ID администраторов (через запятую) | ✅ |

### Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

### Настройка администраторов

1. Получите ваш Telegram ID (отправьте `/start` боту @userinfobot)
2. Добавьте ID в переменную `ADMIN_CHAT_IDS`
3. Перезапустите бота

## 💳 Настройка платежной системы

Для работы системы подписок настройте:

1. **Тарифные планы** - через админ панель
2. **Промокоды** - создание и управление скидками
3. **Обработка платежей** - проверка переводов администраторами

## 📚 Использование

1. Запустите бота командой `/start`
2. Пройдите регистрацию
3. Выберите нужный раздел в главном меню
4. Следуйте инструкциям интерфейса

2. Управление пользователями и подписками
3. Настройка тарифных планов
4. Обработка заявок на оплату
