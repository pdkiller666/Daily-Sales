# Daily Sales — Telegram Bot для управления продажами

Профессиональный мультитенантный Telegram-бот для управления магазинами, продажами, персоналом и подписками. Поддерживает несколько организаций с полной изоляцией данных.

---

## 🚀 Возможности

### 🏢 Мультиарендность (Multi-tenancy)
- Несколько организаций — каждая со своей изолированной базой данных
- Система ролей: **Директор (owner)** → **Администратор (admin)** → **Сотрудник (user)**
- Зоны доступа: по магазину / городу / торговой сети (мульти-выбор JSON)
- Кастомные названия должностей (`custom_title`)
- Инвайт-коды для вступления в организацию
- Суперадмин (env_manager) с возможностью переключения контекста между организациями

### 💰 Продажи и инвентарь
- Быстрая регистрация продаж (одиночная и мультикорзина)
- **Двухуровневый каталог**: сначала категории (с количеством товаров), затем товары внутри категории
- Сортировка товаров: по названию / цене ↑ / цене ↓; поиск по названию прямо в категории
- Быстрый поиск «🔍 Найти товар» по ненулевому остатку через все категории
- Кнопки количества [1, 2, 3, 5, 10, 20, 50] — без ввода текста
- Импорт товаров из Excel (📊 Импорт из Excel)
- Пакетный импорт: «Название;Категория;Цена» — до 100 товаров за раз
- Избранные товары (⭐ Избранное) и недавние (🔄 Недавние) с поиском внутри
- Быстрое подтверждение (⚡ Продать сейчас) при первом товаре в корзине
- Складской учёт с историей изменений
- **Редактирование и удаление продаж** с корректировкой остатков (по одной или за период)
- **Массовое удаление продаж** за период по магазину с автоматическим восстановлением остатков
- **Кросс-продажи**: сотрудник торговой сети может оформить продажу/списание из другого магазина сети

### 🗂 Навигация (Hub-меню)
- **Управление орг.** → Каталог товаров / Упр. продажами / Мотивация / Команда / Упр. магазинами / Google Sheets / Рассылка
- **Каталог товаров** → 🛍 Управление товарами + 📦 Управление остатками
- **Упр. продажами** → ✏️ Редактировать/удалить + 🗑 Удалить за период
- **Мотивация** → 🎯 Система мотивации + 📋 Планы продаж + 🏆 Конкурсы
- **Команда** → 👥 Сотрудники + 💰 Зарплата и смены
- **Аналитика** → 📈 Отчёты + 🏆 Рейтинги
- **Мой профиль** → Редактировать / 📅 Мой график / Уведомления / Подписка / Контакты
- Главное меню: живая сводка за сегодня (`📅 N прод. · X ₽`, `⚠️ Малых остатков: M`)

### 📊 Отчёты и аналитика
- Дашборд для администратора: смены, продажи, мотивация команды, все планы — период Сегодня / Неделя / Месяц
- Дашборд для сотрудника: зарплата, планы, конкурсы — с тем же переключателем периода
- Отчёты по периодам: общий / по магазину / по городу (с ручным фильтром)
- «Текущий месяц» — быстрый отчёт сотрудника с 1-го по сегодня
- Рейтинги продавцов, магазинов, городов (7 дней / этот месяц / прошлый)
- Позиция пользователя вне топ-10
- Поиск по магазину в разделе отчётов
- Все товары без ограничений (длинные списки — с подсказкой «скачайте Excel»)
- Все времена отображаются в часовом поясе пользователя

### 📥 Экспорт в Excel
- Экспорт из любого раздела отчётов (до 50 000 строк)
- **4 листа**: «Детальный отчёт» (с продавцом, ИТОГО), «По категориям» (график), «По продавцам» (график), «По дням» (график)
- Scope-фильтр при экспорте учитывает зону доступа администратора
- Транслитерированные имена файлов

### 🎯 Планы продаж
- Планы для продавца или магазина
- Периоды: неделя / месяц
- Метрики: оборот (₽) / количество (шт)
- Фильтр по категории или конкретному товару (мульти-выбор)
- Редактирование всех параметров плана
- Уведомления о достижении 50% / 75% / 100% — однократно за период
- Прогресс-бары в дашборде и «Моих планах»
- Поиск магазина / сотрудника / категории / товара при создании плана

### 📅 Зарплата и графики работы
- Ставки сотрудников (daily_rate)
- Календарь смен с отметкой рабочих дней
- Время начала и конца смены для каждого дня
- **Шаблоны смен** (⏰ Расписание смен): типовое расписание по дням недели (Пн–Вс), автоматически применяется при добавлении смены
- Сотрудник видит своё расписание и времена смен в разделе «Мой профиль»
- Зарплатный итог за месяц

### 💼 Мотивация и комиссии
- Матрица мотивации: ставки комиссии по товарам / категориям / магазинам
- **Помесячное расписание мотивации**: разные ставки на каждый месяц, архив
- Дополнительные условия (бонусы при выполнении KPI)
- **Совместный режим**: пул продавцов делит общий бонус поровну
- Индивидуальные пороги по магазинам в конкурсах

### 🏆 Конкурсы
- Два режима наград: **total** (победитель по сумме) и **per_sale** (бонус за каждую продажу по тирам)
- Индивидуальные пороги по магазинам
- Корректировка показателей вручную в любой момент
- Автоматическое подведение итогов (APScheduler)
- Фильтры по товарам / категориям / городам / пользователям
- Архив конкурсов с очисткой по подтверждению
- Поиск товара / категории при настройке конкурса

### 🔍 Ручные фильтры и поиск
- Кнопка «🔍 Фильтр» в Отчётах, Рейтингах, Сотрудниках, Прогрессе планов
- Мульти-выбор по магазину / городу / торговой сети
- Scope роли — потолок, ручной фильтр — пол
- **Динамический поиск** во всех больших списках: магазины, сотрудники, товары, категории

### 💎 Монетизация (Freemium)
- Тарифные планы: **Бесплатный** (0₽) / **Базовый** (500₽/30д) / **Стандарт** (1200₽/90д) / **Премиум** (4000₽/365д)
- Пробный период 14 дней = Премиум-уровень доступа
- Промокоды со скидками и лимитами использования
- **Два провайдера оплаты**: СБП (ручное подтверждение скриншота) / ЮKassa (автоматически через API)
- Настройка ЮKassa прямо из бота (shop_id, secret_key, return_url)
- Авто-отклонение pending СБП-заявок старше 72 часов
- Upsell-уведомления при истечении триала (за 14/7/3/1 день и сразу после)
- Квитанция при активации подписки

### 🔗 Интеграции
- **Google Sheets**: автоматический экспорт продаж в таблицу при каждой продаже
- Авторизация через OAuth 2.0 Device Flow (без браузера)
- Настраивается один раз администратором; продажи всех сотрудников попадают в таблицу автоматически
- Доступно с тарифа **Стандарт** и выше

### 🔔 Уведомления
- Уведомления о низких остатках
- Уведомления о новых продажах за 24 часа
- **Уведомления о продажах смены**: при каждой продаже — push коллегам, стоящим в смене в том же магазине (настраиваемо)
- Массовые и запланированные рассылки от администратора
- Запланированные уведомления: ввод в локальном времени → хранение UTC → отправка точно по времени
- Кнопка «✅ Прочитано» на всех push-уведомлениях — удаляет сообщение
- Напоминания об окончании подписки (за 14 / 7 / 3 / 1 день)

### 🎓 Onboarding и подсказки
- Welcome-попап при первом входе (роль-зависимый текст)
- Inline-подсказки при первом визите каждого раздела (однократно)
- Кнопка «✅ Понятно!» закрывает подсказку

## 🛠 Быстрый старт

### Требования
- Python 3.11+
- Replit (рекомендуется) или любой Linux-хост

### Установка

```bash
git clone https://github.com/pdkiller666/Daily-Sales.git
cd Daily-Sales
pip install -r requirements.txt
```

### Переменные окружения

| Переменная | Описание | Обязательно |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | ✅ |
| `ADMIN_CHAT_ID` | Telegram ID супер-администратора | ✅ |
| `GITHUB_TOKEN` | Токен для деплоя на GitHub | для деплоя |
| `GOOGLE_OAUTH_CLIENT_ID` | OAuth client_id для Google Sheets | для интеграции |
| `GOOGLE_OAUTH_CLIENT_SECRET` | OAuth client_secret для Google Sheets | для интеграции |

На Replit все переменные хранятся в **Secrets** (не в `.env`).

> **Google Sheets OAuth**: при создании OAuth-клиента в Google Cloud Console выбирать тип **«TVs and Limited Input devices»** — только он поддерживает Device Flow.

### Запуск

```bash
python main.py
```

## 🏗 Архитектура

- **Multi-tenancy**: каждая организация получает изолированную SQLite БД (`data/tenants/org_*.db`)
- **AsyncDatabase wrapper**: `get_db()` возвращает `AsyncDatabase` — все методы автоматически оборачиваются в `asyncio.to_thread`; thread-local connection pool переиспользует соединения внутри потока
- **Anchor message pattern**: все FSM-флоу редактируют одно сообщение через `fsm_edit()`
- **Hub-навигация**: разделы сгруппированы по логике (Каталог, Продажи, Мотивация, Команда, Аналитика) — 1 кнопка в родителе раскрывает хаб с 2–3 подразделами
- **APScheduler**: 9 фоновых задач (продажи, отчёты, конкурсы, уведомления, бэкап, upsell, авто-отклонение платежей) — стартуют в разные секунды минуты
- **Timezone-aware**: все времена хранятся как UTC, отображаются в TZ пользователя
- **Filters**: scope роли — потолок, ручной фильтр — пол; global FSM key `admin_filter`
- **Hosting**: Amvera (production, persistent mount `/app/data`), Replit (development)
- **Payments**: pluggable провайдеры (СБП / ЮKassa) через `payment_provider.py`
- **Migrations on access**: `create_tables()` вызывается при каждом `get_db()` — миграции применяются автоматически
- **Cross-tenant queries**: для JOIN между tenant-DB и main.db (например, роли сотрудников) используются два раздельных запроса с объединением в Python
